# Uk 的独立测试与有效性验证

本组不训练网络、不更换权重、不调反馈增益，也不修改已有学习或控制结果。新增两类验证：一是在真正未参与训练和检查点选择的测试轨迹状态上评价力残差；二是采用逐条初值匹配的名义参考，检验原先大初始跟踪偏差之外的补偿作用。原有公共零初态参考的负结果全部保留。

## 控制定义与公平条件

真实对象仍为同一两模态梁 H*，名义模型仍为 H0。实际输入是一维磁场比，方向 b(X)=d cos(d·X)，作用于两个动量分量。学习残差 rhat=J∇Hhat−J∇H0，补偿取 u_ff=−bᵀrhat_Y/(bᵀb)，与原固定反馈相加后将总输入限制到±.2。Oracle使用相同模型的真实遗漏力−d[sin(theta)−theta]，不是最优控制器。

比较保留 none/oracle/GR/GC、五个原模型种子、全部40测试初值、I/G与II、III。I与合法原中点生成函数控制G已经证明并数值核对等价，复用同一轨迹，不算独立方法或重复。

本轮没有更改 kp=1、kd=.5、uref、输入预算、plant或任何已训练权重。运动学残差和动量中与b正交的残差无法由该输入独立抵消，分别报告。

## 真正独立的共同测试状态

在新性能计算前固定：每条原有held-out连续测试轨迹，在不晚于旧控制终点7.994745秒的保存时刻中等距取64点，全部40轨迹共2560点。最后可用保存时刻约7.987738秒。所有policy在完全相同状态点评价，避免把控制器经过不同状态造成的变化误写成预测精度差异。

这些状态来自未用于训练或检查点选择的测试轨迹；原来的2284验证中点仍原样保留，但其结果不再被当作新测试误差。统计先计算每条轨迹64点×2力分量的RMS，平均种子内8条，再跨5种子报告均值和样本SD。2560点不视作2560个独立重复。

| 补偿 | 测试补偿后力残差RMS，×10^-6 | 运动学残差RMS，×10^-6 | 正交力分量RMS，×10^-6 |
|---|---:|---:|---:|
| 无补偿 | 3.877 ± 1.085 | 0 | 0 |
| Oracle | 接近零 | 0 | 接近零 |
| GR | 2.927 ± .465 | 3.040 ± .554 | 2.069 ± .492 |
| GC | 2.229 ± .683 | 2.135 ± .997 | 1.458 ± .328 |

GR相对无补偿在4/5块降低力残差，保留种子211略变差的反例；GC在5/5块降低。此处量是状态点上的力残差，不是总跟踪误差。

另外在已有各自闭环轨迹的64个保存步起点上重算同样指标，并利用记录的实际保持输入与同状态无补偿反馈之差，计算含总输入预算的实际增量残差。该结果存 `own_closed_loop_force.json`；各方案经过状态不同，不能把其绝对均值作为同点泛化能力比较。保存的实际输入与独立重建命令差低于2e-12。

## 原控制结果独立复算与重复单位

已从旧NPZ独立重算全部360案例、1200条响应的杆端、全状态、尾段误差及输入努力，最大差8.88e-16。原公共零初态参考的结论不变：较低的投影力误差没有稳定转化为40初值跟踪收益。

零初值辅助响应中，none和oracle在不同权重块的轨迹完全相同，5个保存块只对应1条物理响应；GR/GC对应5个已训练模型的变化，不能称为5组随机初值。`summary.json` 显式记录这一重复关系。

## 初值匹配的名义参考诊断

父任务提出该诊断后，先单独保存 `matched_initial_reference_amendment.json`，再生成参考或计算结果。每条原测试轨迹的名义参考由 H0+相同uref 从与plant相同的初值出发；所有policy共享该条参考。真实plant、增益、权重、输入上限、插入方式及物理时域均不变。

全部40初值、4policy、3个不同映射、h0与h0/2均计算，共960条新响应。该组用于减少共同零参考造成的大初始偏差，属于机制隔离诊断；参考轨迹本身也随初值改变，不能将旧新两组的绝对误差直接相减解释为Uk收益，也不是新种子确认。

I/G杆端RMSE（μm）：

| 补偿 | h0 | h0/2 |
|---|---:|---:|
| 无补偿 | 4.791 ± .436 | 1.572 ± .137 |
| Oracle | 4.653 ± .419 | 1.379 ± .085 |
| GR | 4.679 ± .427 | 1.416 ± .104 |
| GC | 4.671 ± .428 | 1.405 ± .101 |

I/G两档步长中，GR和GC相对无补偿在杆端及完整状态指标均5/5块改善。h0/2时，none−GR杆端配对差为0.156806±0.056768 μm，none−GC为0.167546±0.059598 μm，平均种子内相对改善为9.847%和10.519%。

GC相对GR的杆端配对收益在h0/h0/2分别为0.008373±0.003165和0.010740±0.005273 μm，两档均5/5；完整状态仅4/5块更好。该小量差异限定于既有权重、参考和固定反馈，不构成复值控制的普遍优越结论。全部II/III结果和反向方向也保留在CSV/JSON中。

峰值总输入 .052014、补偿 .00022757，无饱和；最大模态半径 .277085，超过原学习初值上限 .20，最大角变量 .109315。该诊断涉及该幅值范围的外推，未据此宣称网络有已认证外推保证。最大中点残差1.07e-16。参考的预定每种子第一条轨迹用更紧DOP853容差核对，最大状态差约1.9e-11；这是参考容差敏感性，不是严格误差界。

## 核验和文件

- `protocol.json`：2560共同点、各自闭环点、重复单位与原773输入哈希。
- `matched_initial_reference_amendment.json`：新增参考诊断先验定义。
- `common_test_force.json/.csv`、`own_closed_loop_force.json`：逐轨迹、种子与聚合力误差。
- `old_tracking_recomputed.json`：旧结果的完整独立复算与配对。
- `matched_references/`、`matched_initial/`：新参考、960响应与原始输入记录。
- `matched_initial_summary.json`、`matched_initial_comparison.csv`、`matched_initial_paired.csv`：全部插入、步长、policy、指标和配对方向。
- `manuscript_force_table.tex`、`manuscript_matched_table.tex`：两张紧凑供稿表，未自动改主稿。
- `independent_verification_full.json`：完全不导入分析实现，以导出标量能量的复步长导数重算140组力状态集，并独立重算全部2160条旧新轨迹指标。力指标最大差4.84e-16，轨迹指标差0，773个旧输入哈希未变。
