# 受控式（36）的收敛与辛结构核验

本实验针对原稿加入控制后的收敛要求，把连续受控系统、实际采样反馈和固定保持输入序列的误差分别测量。所有参数在计算前写入 `protocol.json`，未训练模型、调增益或筛选有利初值。旧实验与旧输入不变。

## 维度、控制和共同条件

梁模型仍是原保守两模态模型，位置和动量各为二维，状态为四维，`M=diag(1/nu)` 为 **2×2** 质量矩阵。实际输入只有标量磁场比 `u=By/B0`；步后势冲量为 `(0,h*u*d*cos(d·X))`，不是四个独立执行器。

方法 I 为受控隐式中点，II 为自由中点后完整势冲量，III 为半势冲量—自由中点—半势冲量。原生成函数的合法标量控制构造 G 已在旧实验320组独立方程求解中验证与 I 等价，因此 I/G 只计为同一结果。

全部梁实验固定原时域约7.994745秒，步长为 `4h0,2h0,h0,h0/2,h0/4`，`h0=0.009999813692`，输出时刻均为1142个共同点。学习策略使用全部5种子已有GR、GC权重；无补偿只是一条确定性基线，未复制为5个独立物理重复。

## 三种参考必须区分

### A 光滑外生输入

沿用原平滑 `u_ref(t)`，所有离散方法在步的时间中点评价输入。独立自适应DOP853连续流作参考。初值预先固定为零初值和种子17、43、91各自第一条原测试初值，共4条，不按效果挑选。

零初值分离受迫响应的观察阶：I/G约2.000003，II约1.012058，III约2.000003。其余非零初值结果全保留；其总误差可能受自由模态相位影响，不能只据其表观斜率认定输入插入阶数。

### B 实际采样反馈对连续反馈流

在步起点根据数值状态计算原反馈及补偿后整步保持，与其自身的连续反馈流比较。这一差值同时包含输入采样保持误差与步内积分误差。保留全部GR/GC权重及无补偿。

旧零初值4档轨迹直接按哈希复用；只新算缺少的4h0档，所有误差重新对齐到同一个收紧容差的连续流。I/G最细观察阶为1.006800–1.006806，II为1.002828–1.002831，III为1.006800–1.006806。

旧连续流与本轮紧参考的最大状态差1.53e-12。没有把不同控制器轨迹之间的差异当成数值误差。

### C 同一冻结输入序列的积分误差

对每个步长，在各自连续反馈轨迹的步起点采样控制量，先把整条序列冻结，再让 I、II、III 使用完全相同的序列。参考解是**该序列对应的连续分段常输入流**。

这用于隔离步内积分误差，不是又一个真实采样反馈控制器。保持流与原连续反馈流的差另行保存，不能把该保持误差混进方法积分误差。

参考由独立八阶DOP853固定步RK核每保持区间2子步计算，再对每个设置用4子步加密；最大差9.39e-15。运行前用自适应DOP853及线性矩阵指数核对参考核，单步最大差8.33e-17。它是高精度数值参考与敏感性检查，不是严格参考误差界。

最细观察阶：I/G为1.999980–1.999982，II为1.012059–1.012062，III为1.999980–1.999982。

## 非单位质量和不相容反例

另设明确的标量格式基准 `m=2,k=1,u(t)=.05sin(.7t)`，初值 `(q,p)=(.1,.2)`，固定终点5。以包含正弦/余弦的4×4增广线性系统矩阵指数取得精确参考。

| 方法 | h=.0125终点状态误差 | 最细观察阶 |
|---|---:|---:|
| I/G | 3.67801e-6 | 1.99994 |
| II | 4.75488e-4 | 0.99265 |
| III | 3.67801e-6 | 1.99994 |

负对照把步后动量增量错误地写成 `u(t_mid)`，省略步长h；当h从.2降至.0125，终点误差从.33653增至6.79193，无法逼近同一个连续受控系统。该变换在固定外生输入时仍可保辛，说明保辛并不替代时间一致性和收敛。

这只是明确的不相容示例，不是建议使用的控制器，也不代表原稿必须把力幅值本身缩小为O(h)：应随h缩小的是加到状态上的一步增量。

## 结构核验

在零初值及每个模型对应第一条测试初值上，分别计算固定输入参数和完整反馈映射的Jacobian。完整反馈包括 `Phi_u * du/dx`，并在最大、最小步长用独立状态差分核对。

- 固定输入辛缺陷最大5.67e-16。
- 完整反馈辛缺陷最大0.02106。
- 完整Jacobian与独立状态差分最大差2.76e-11。

随h减小的反馈缺陷不表示固定步长下严格保辛。该结论也不延伸至任意向量修正或一般非保守系统。

## 数据、独立核验和复算

- `smooth_external_records.json`：60条方法/初值/步长指标。
- `sampled_feedback_records.json`：165条实际反馈指标，其中132份旧轨迹复用。
- `frozen_sequence_records.json`：165条方法指标，全部3方法逐值共享控制序列和保持流参考。
- `scalar_m2_records.json`：20条标量正反例轨迹。
- `structure_records.json`：330组结构诊断，132组独立Jacobian差分。
- `summary.json`：全部误差和逐级观察阶，保留所有方法与模型。
- `manuscript_table.tex`、`manuscript_values.json`：紧凑稿件表及完整数值范围。
- `independent_verification.json`：不导入主实验实现，独立复算390条指标、20条精确标量参考、全部阶数和序列一致性；最大指标差2.23e-16，153份原输入哈希一致。
