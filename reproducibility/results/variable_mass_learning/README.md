# 变质量坐标下的式36学习实验

本实验检验式（36）在质量矩阵随构型变化、二次收缩项不为零时的数据生成与实复网络学习。它使用原两模态梁的可逆正则点变换，不引入新的梁质量本构或物理标定。

## 对象和坐标

原物理模态坐标为 `(X1,X2,Y1,Y2)`，原 Hamiltonian、物理系数、静态余弦磁势与全部训练/验证/测试初值保持一致。新坐标取

`X_j = q_j + q_j^3`, `Y_j = p_j/(1+3q_j^2)`。

因为 `Y^T dX = p^T dq`，此变换正则；新坐标质量逆矩阵为 `diag(nu_j/(1+3q_j^2)^2)`，严格正定且随 q 变化。保守动量方程必须包含 `Delta_i = -.5*p_mid_i^2 * d(M^-1_i)/dq_i`。本实验中的质量变化是同一梁在不同正则坐标中的表示，不表示机器人实体质量发生变化。

## 数据与训练

教师轨迹是在新坐标中重新求解式（36）的中点隐式方程；没有将旧离散轨迹直接变换后冒充新格式数据。每一步的中点状态与相邻状态差商组成监督对，标签加入独立有界均匀噪声 1e-6。连续参考由新坐标连续方程的独立 DOP853 积分得到。

固定五个种子 `17,43,91,137,211`，每种子 12 条训练轨迹约 2 秒、4 条验证约 4 秒、8 条测试约 15.993 秒。完整轨迹分开划分。四组为 R/C/GR/GC，各 673 个实参数、10000 次 Adam 更新、batch512；原训练器的归一化、学习率和固定验证检查点规则一致。

G 先验是原物理二次主部的拉回：`.5 sum nu_j*(f(q_j)^2+p_j^2/fprime(q_j)^2)`，包括正确的构型依赖动能。在新坐标里它不是二次多项式。没有把变质量动能忽略后仍声称提供了完整物理先验。

所有网络输出实值保守能量（H+i0），梯度在新正则坐标下计算。任意学习能量通过统一隐式中点推进；不能因此声称任意网络都保持原物理 M/K/Delta 的矩阵参数形式。所有最终误差先映回原物理 `(X,Y)` 坐标计算，杆端输出沿用原 `tip_map_m`。

## 评价与对比

预测分别使用原步长 h0 和 h0/4，固定权重及共同输出时刻。每条轨迹先算时间误差，种子内平均 8 条，再跨五种子报告均值与样本标准差。连续参考和同步长非线性教师分开评价，同时保留无网络 H0 物理主部基线。

五项配对为 `R-GR`、`C-GC`、`R-C`、`GR-GC`、`(GR-GC)-(R-C)`，均在种子内先相减。正值表示前一个模型误差更大。计算全部种子、全部四组与全部步长，不按结果筛选或调参。

## 文件与复算

- `protocol.json`：运行前固定的实验协议及源代码哈希。
- `implementation_verification.json`：正则点变换、链式法则、式（36）直接矩阵代回、非零 Delta、辛切映射与收敛核验。
- `data/seed_*.npz`：所有训练/验证数据及独立测试参考；状态顺序为 q1,q2,p1,p2。
- `seed_*/{R,C,GR,GC}_weights.npz`：20 份端到端训练权重，包含 `mass_alpha=1`。
- `seed_*/*_h{1,4}.npz`：预测、连续参考、同步长教师、H0；轨迹形状为 `[trajectory,time,4]`。
- `summary.json`、`paired_contrasts.csv`：完整均值、样本标准差与五项配对。
- `independent_verification.json`：不导入实验实现的独立导出能量复步长求导与轨迹统计核验。

在已具备原工程依赖的科学 Python 环境中，从工程根运行：

```powershell
python -B code/variable_mass_learning.py --stage all
python -B code/variable_mass_learning_verify.py
```

已有数据、权重和预测按来源哈希核验后复用；不覆盖旧实验。模块接口 `to_physical/from_physical` 负责坐标映射，`model_field/model_energy` 是真实场和能量，`trainer()` 后可调用 `numpy_energy_field(x,weights)`；编译接口为 `params_for(weights)`、`learned_field(x,params,prior)` 及 `neural_rollout`。

## 结论适用范围

该实验补充非零 Delta 分支的实际数据训练与五项对比，不认证一般阻尼、独立外力、接触、任意非交换物理矩阵或非零耗散虚部。观察阶是所测算例的数值结果，不替代一般阶数证明。新坐标的选择可能影响有限容量网络的学习难度，实复差异须限定到这一固定坐标协议。

独立核验通过：20份权重的复步长能量梯度、训练输入尺度、验证检查点、320条网络轨迹、80条H0轨迹和40项配对汇总均一致。数据标签对真实中点场的最大差约3.81e-14；独立检查点MSE最大差6.37e-19；保存轨迹指标复算差0。
