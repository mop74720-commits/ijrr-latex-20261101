# 固定权重、纯二次物理基线与步长加密

本实验使用 `results/neural_learning_10000/` 中全部20组已保存权重，保留五个种子、各八条测试轨迹，以及原914个输出时刻。实际终点为15.992993212174294秒。没有重训、重新选择权重、种子或测试轨迹。协议先保存，再执行字段核对和数值求解。

模型为无网络的 `H0` 以及 `R/C/GR/GC`。预测步长为原无量纲步长 `h=0.009999813692010036` 的1、1/2、1/4和1/8。每一档均重新计算同一完整非线性Hamiltonian的中点教师；连续参考使用原保存DOP853解。所有组的输出网格相同。

## 主要结果

杆端连续参考RMSE在原步长下，`H0=77.466±8.552 μm`、`GR=78.263±8.899 μm`、`GC=78.298±8.670 μm`。在 `h/4` 下，`H0=4.350±0.442 μm`，仍低于GR和GC，二者种子内配对收益均为0/5正值。

在 `h/8` 下，杆端连续RMSE为 `H0=1.563±0.342 μm`、`GR=1.335±0.342 μm`、`GC=1.287±0.129 μm`。配对收益 `H0-GR=0.227517±0.445279 μm`、`H0-GC=0.276164±0.275509 μm`，均只有4/5种子为正。这里的标准差为五种子样本标准差，不是置信区间。

同一最细步长下，完整正则状态的相对L2误差反而是 `H0=0.001353±0.000101`、`GR=0.002075±0.000663`、`GC=0.002104±0.000202`；H0在全部五种子上更低。因此，杆端RMSE的平均收益不构成完整状态精度优势，也不支持普遍的网络或复数表示优势。

R/C在最细步长下的连续杆端误差仍分别为约0.870277和0.879816毫米。对同步长非线性教师的误差在加密后趋于稳定：H0约1.647 μm、GR约0.586 μm、GC约0.408 μm。加密没有消除学习向量场的模型误差。

训练中点的非线性/线性回复力L2比为 `1.330705e-5±2.699924e-6`。纯二次模型的精确连续轨迹与非线性连续参考之间约有1.647 μm的杆端差异，而原步长下单独的二次中点积分误差约为78.319 μm。粗步长的积分误差与模型误差存在部分抵消；两项RMSE不能简单相加或相减作为误差分解。

## 统计与文件

每条轨迹先在共同的914时刻计算时间RMSE；每个种子平均其八条轨迹RMSE，最后报告五种子均值与样本标准差（`ddof=1`）。状态误差同样先计算每轨迹相对L2，再在种子内平均。时间样本和同种子的八条轨迹不当作独立训练重复。

- `protocol.json`：执行前确定的模型、网格、求解与统计口径，以及47个原始输入文件的SHA256。当前路径协议为`schema_version=2`，所有输入标识均相对于工程根目录，严格核对完整子路径、文件内容和非路径参数。
- `protocol.legacy_absolute_paths.json`：首次迁移前旧协议的原始字节备份。仅将已知旧根`E:/1030/IJRR_1025_20261030`下的完整输入路径映射到项目相对标识；未知绝对来源、同名但不同子路径、参数变化或内容哈希变化均拒绝，重复迁移不再改写协议。
- `environment.json`、`execution_script.py`：实际数值执行环境与当时的完整脚本快照，保留原始内容和历史哈希。当前主脚本随后补充了汇总、图表、已完成结果的重复运行保护及路径协议迁移；摘要中的`analysis_script_sha256`记录最近一次汇总使用的脚本，不代表重新计算过数值轨迹。
- `field_verification.json`：20个网络与原NumPy字段的独立核对及能量差分检查。
- `common_seed_*.npz`：共同网格、连续参考、纯二次精确连续解和物理读出。
- `seed_*/h*_trajectories.npz`：五模型与同步长非线性教师在共同输出网格上的轨迹，不保留内部子步。
- `trajectory_metrics.csv`：800条逐轨迹记录。
- `seed_metrics.csv`：100条模型/步长/种子记录，包含全部R/C结果。
- `paired_seed_differences.csv`、`paired_summary.csv`：H0减各网络的逐种子差，以及每档均值、样本标准差和正值种子数。
- `controls.csv`：教师与连续参考、纯二次积分误差和纯二次模型误差。
- `solver_diagnostics.csv`：输出网格、原h重现、残差和迭代数。网络与教师残差检查覆盖全部内部步；解析H0的残差检查是在各保留网格状态上再施加一个解析Cayley子步。
- `summary.json`、`verification_summary.json`：完整汇总和独立结果文件核查。

网络最大中点残差为 `1.7191e-15`，教师最大残差为 `6.0553e-17`；原h的20个网络轨迹与保存轨迹最大状态差为 `2.9000e-10`，五个教师轨迹与原保存教师相同。20个Numba字段与原NumPy字段的最大差为 `6.6613e-16`。独立从全部轨迹文件复算的杆端及状态种子统计与CSV一致；47个原输入哈希保持不变。

## 命令

进入完整工程根目录，使用已有NumPy、Numba、Matplotlib依赖的科学Python解释器：

```powershell
python -B "./code/neural_physics_refinement.py" --stage plan
python -B "./code/neural_physics_refinement.py" --stage verify
python -B "./code/neural_physics_refinement.py" --stage run --workers 4
```

已有完整结果时，`--stage run`保留数值输出与原执行元数据，只重新汇总和渲染。单独重画使用 `--stage assets`。正文表为 `manuscript/tables/neural_refinement.tex`，标签 `tab:neural_refinement`；PDF/PNG图为 `manuscript/figures/neural_physics_refinement.*`，建议标签 `fig:neural_physics_refinement`。图同时展示杆端RMSE与完整状态误差，误差棒为种子样本标准差。

迁移应保留完整工程结构和47份输入文件，旧绝对路径不要求仍可访问。路径变更不改变输入哈希、权重、轨迹或统计口径。窄回归可运行`python -B "./audit/test_refinement_protocol_portability.py"`；它物理复制输入与缓存到含空格和中文的临时目录，验证`plan`、字段`verify`、已完成`run`缓存及拒绝篡改路径，不训练或全量重算轨迹。核验记录为`audit/refinement_portability_verification_20261031.json`。
