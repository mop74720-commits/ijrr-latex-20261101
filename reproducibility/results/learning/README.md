# 式（36）保守分支的匹配解析特征学习结果

本目录保存2026-10-30实际重新生成的数据、20次拟合、40秒独立初值预测、权重及检查结果。原稿及旧工程未修改。该实验只覆盖常质量、无耗散和驱动的保守分支，模型为固定解析特征和训练线性读出；不是端到端复值 MLP，也不验证一般复值 `H+iG`、完整四场系统或 KAM 环面存在性。

## 完成情况

- 5个独立数据/噪声种子：17、43、91、137、211。
- 每种子12条训练、4条验证、8条独立测试轨迹；分别2、4、40秒。
- 每种子3432个中点训练样本和2284个中点验证样本；测试数据形状为 `(8,2285,4)`。时间样本不是独立重复。
- 四组 R、C、GR、GC，共20次真实拟合与预测；全部预测为有限值，未筛除失败模型。
- 数据均由固定式（36）的保守常质量特例生成。独立 DOP853 仅用于测试参考。
- 全部模型使用相同隐式中点预测积分器；泛化四次能量含动量四次项，不宣称学习器都保留原物理系数参数化。

## 主要结果

对独立式（36）教师轨迹的末端位置 RMSE，五个种子的均值和样本标准差：

| 模型 | 平均值 ± 样本标准差（mm） |
|---|---|
| R | `(3.4138644 ± 1.6792607) × 10^-5` |
| C | `(3.4138644 ± 1.6792606) × 10^-5` |
| GR | `(1.8435735 ± 1.0696994) × 10^-5` |
| GC | `(1.8435735 ± 1.0696994) × 10^-5` |

五项配对差值，正值的含义按 `audit/learning_protocol.md` 中的指标方向：

| 配对差 | 均值 ± 样本标准差（mm） |
|---|---|
| R − GR | `(1.5702909 ± 1.5078156) × 10^-5` |
| C − GC | `(1.5702910 ± 1.5078155) × 10^-5` |
| R − C | `(-4.1744 ± 12.4731) × 10^-13` |
| GR − GC | `(1.1219 ± 2.8438) × 10^-16` |
| (GR − GC) − (R − C) | `(4.1755 ± 12.4738) × 10^-13` |

物理先验在4/5种子中降低末端预测误差；seed17轻微变差。上述统计是描述性汇总。实复函数空间配平后结果数值等价，没有得到复表示本身优于实表示的证据。

**上述微小数值是相对于离散教师的学习误差，不能写成连续物理系统的预测精度。** 相对于独立高精度连续参考，四组模型的平均末端 RMSE 均约 `0.203769 mm`，主要由该步长下的长期相位离散误差决定。训练拟合准确并不消除积分器的长期相位误差。

学习器自身的能量最大相对漂移约 `1.1e-8`，但这不意味着轨迹相位准确，也不构成 KAM 认证。

## 正确性检查

`implementation_checks.json`：

- 20个初值的一步直接式（36）结果与中点实现最大差：`2.7756e-17`。
- 该保守分支的解析切映射辛结构缺陷最大值：`2.2376e-16`。
- 匹配实复特征梯度差：`1.3878e-17`。
- 步长减半观测阶：`1.94894`、`1.98939`、`1.99749`；此为所测试特例的实测值，不改写冻结原稿的一般声明。
- 40秒独立参考解容差收紧100倍，最大状态差：`3.9958e-10`。

`output_checks.json`：

- 20个模型预测全部有限，5份共享数据哈希与 `data_ready.json` 一致。
- 在每模型20个独立状态上，旧冻结特征实现的能量梯度与新预测内核的梯度共400点比较，最大差 `3.3307e-16`。

`data/seed_*_diagnostics.json` 逐种子记录教师隐式残差、干净增量标签与物理中点向量场的一致性，以及独立参考设置。`fits/*_metrics.json` 记录各模型的求解残差、能量漂移及计算成本。

## 文件与复现

- `config.json`：运行前固定的实验配置。
- `source_manifest.json`、`inputs/`：原参数、原特征实现及旧训练脚本的按字节副本与 SHA256；旧训练脚本未执行。
- `data/seed_*.npz`：每个种子的共享训练、验证、测试数据及物理坐标说明。
- `data_ready.json`：共享数据文件的 SHA256。
- `fits/seed_*_{R,C,GR,GC}.npz`：实际权重、完整能量系数、预测轨迹和自身能量。
- `summary.json`：结构化汇总。
- `model_metrics.csv`、`trajectory_metrics.csv`：逐模型和逐测试轨迹指标。
- `paired_contrasts.csv`：逐种子的五项配对差。
- `teacher_discretization_metrics.csv`：教师轨迹对连续参考的误差。
- `environment.json`：实际解释器、平台、NumPy版本及执行脚本哈希。

在项目目录运行：

```text
D:/Apps/Miniconda3/python.exe -B code/learning_experiment.py --stage data
D:/Apps/Miniconda3/python.exe -B code/learning_experiment.py --stage fit
```

已存在的教师数据会保留。重新拟合会重新写入本目录的拟合输出；应先保存需要保留的旧实验版本。数据输入与原稿均不会被修改。
