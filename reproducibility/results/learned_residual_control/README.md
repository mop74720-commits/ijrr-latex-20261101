# 学得磁势残差的标量输入补偿

本组将已保存的 GR/GC Hamiltonian 权重实际接入磁场控制，比较无补偿、精确残差参照、实数学习残差及复数学习残差。全部三种原控制插入方式、两个主步长与所有 40 条测试初值均已运行，另保留零初值响应的四级步长核对。没有重新训练、筛选权重或按控制效果调整增益。

核心结果：验证中点上的力残差经实际端口投影后减小，但固定反馈的有限时域跟踪收益很小且有反向种子，尚无稳定的复值控制优势。原生成函数控制的一个合法有势实例已独立求解，和步内中点方案数学等价；不把相同算法重复计为优势。

## 模型、参考与符号

真实仿真对象保持原两模态梁 Hamiltonian h*。名义模型 H0 只保留已知二次能量，遗漏非线性静态磁势。公共参考由 H0 在原有平滑输入 u_ref 下从零初态积分生成，所以与旧 control_comparison 的完整 h* 参考不同，比较限于本组共同参考。

学习残差为 rhat=J grad(Hhat)−J grad(H0)，真实遗漏动量力为 rY=−d[sin(theta)−theta]。真实标量磁场方向 b=d cos(theta)，补偿取 u_ff=−bᵀrhatY/(bᵀb)。Oracle 因而是 [sin(theta)−theta]/cos(theta)，负号用于抵消实际对象的遗漏力。运动学残差和与 b 正交的学习动量残差没有当作独立执行器施加。

总输入为原反馈加 u_ff 后限幅到 ±0.2，kp=1、kd=0.5、平滑 u_ref 均沿用旧控制比较。所有控制在步起点采样状态后保持。真实 plant 仍包含非线性磁势；没有用 H0 替换 plant 来人为获得理想补偿。

## 生成函数控制 G

在原方法的中点坐标 Q=(Xnew+Xold)/2、P=−(Ynew+Yold)/2 中，固定本步输入 u 后定义

    phi^[1]_(h,u)(Q,P) = −h h*(Q,−P) + h u sin(dᵀQ),
    (DeltaY, DeltaX) = grad_(Q,P) phi^[1]_(h,u).

这正好给出受控中点 I。`--stage generator` 从旧状态出发，独立用四维 w 残差求解 G，而不调用 I 的标量化求解器；320 组核对的 I−G 最大状态差为 5.55e−17，生成梯度残差 2.75e−17。另对上述标量 phi 差分求梯度，差不超过 1.52e−13。通过后，I/G 复用同一轨迹，不算两个独立统计重复。

II 是完整步后势冲量，原 III 是半冲量—自由中点—半冲量，仍作辅助对照。一般向量 U 要成为生成梯度，需要相应 Jacobian 对称等可积条件；这里没有将任意反馈向量塞入生成梯度。即使每步保持输入对应有势系统，完整反馈映射还包含 du/dx，不能据此宣称闭环保辛。

`protocol.pre_generating_control.json` 保留最初协议字节；`protocol_amendment_G.json` 在任何长期控制轨迹运行前记录了 G 的加入。

## 主比较

种子 17、43、91、137、211 各复用 8 条独立测试初值，合计 40 条；每个种子使用其对应已保存 GR/GC 权重。公共物理时域为 7.994745 秒，步长为 h0 与 h0/2，h0=0.009999813692（无量纲时间）。先逐轨迹计算时间域误差，再在每个种子块内平均 8 条，最后跨五块报告均值和样本 SD。

下表仅列 h0 的 I/G；三种插入方式及两个步长的完整数值在 `manuscript_tables.json` 与 `manuscript_comparison.csv`。

| 补偿器 | 杆端跟踪 RMSE（mm） | 状态相对跟踪误差 | 控制努力积分 u²dt（s） |
|---|---:|---:|---:|
| 无补偿 | 0.745319590 ± 0.127065665 | 1.603345106 | 0.0130668942 |
| Oracle | 0.745319035 ± 0.127066639 | 1.603347807 | 0.0130670316 |
| GR | 0.745295844 ± 0.127093989 | 1.603305271 | 0.0130668534 |
| GC | 0.745322445 ± 0.127081524 | 1.603359649 | 0.0130669000 |

这里的控制努力不是已标定的实际执行器耗能。

I/G 下，无补偿减 GR 的杆端配对差为 0.023747 ± 0.038454 μm，GR 在 3/5 块改善；无补偿减 GC 为 −0.002855 ± 0.022721 μm，GC 在 2/5 块改善。GR−GC 为 −0.026602 ± 0.035273 μm，GC 仅在 1/5 块更优。结果全部保留，不把某个种子的正向差值写成普遍控制收益。

精确抵消遗漏力也不等于最小化当前固定反馈的有限时域跟踪 RMSE。初始状态偏差、反馈律、输入保持和观测投影同时影响该指标。Oracle 的结果用于说明可实现的残差匹配上限，而不是“最优控制器”。

## 零初值与闭环数值收敛

为分离大初值误差，计算前已经规定同一零初值下的 2h0、h0、h0/2、h0/4 响应。每个控制器还与它自己的独立 DOP853 连续反馈流比较，避免把不同控制律之间的差异当成离散误差。

I/G 的闭环状态观察阶约由 1.032 趋于 1.007；三种插入方式均受步起点采样保持影响。这是当前完整采样反馈响应的观察阶，不是受控系统的二阶定理，也不推翻固定光滑外生输入下中点的二阶结果。

零初值 h0 下，I/G 杆端误差为无补偿 1.681690 μm、Oracle 1.678856 μm、GR 1.669712 μm、GC 1.663087 μm。该辅助工况的微小收益与 40 初值主比较同时提供，不能只挑零初值作为优势证据。

零初值 none/oracle 在不同权重种子下是同一条基线响应的复用，不是五次独立物理重复。GR/GC 在五个不同已训练模型下有不同响应。

## 核验与边界

- 360 个完整案例档案、1200 条响应全部成功：40 初值主比较 960 条，零初值辅助比较 240 条；没有遗漏失败。
- 从保存的 NPZ 独立重算 1200 条轨迹的杆端/状态误差及输入努力，最大差 3.55e−15。
- 19 份原始输入（物理参数、数据、权重及旧实现代码）哈希一致；实际执行脚本、快照及环境记录哈希一致。
- 最大中点残差 5.77e−17；峰值 |u|=0.180094<0.2；最大 |u_ff|=0.000128534。
- 120 组固定输入/完整反馈 Jacobian 核验中，固定输入辛缺陷最大 5.21e−16；完整反馈约 0.00548。链式导数与独立差分一致。
- 保存轨迹的最大模态半径约 0.226，略超原学习初值上限 0.20。最大角变量约 0.0903 rad；这些是数值范围记录，不代替物理有效性或网络外推保证。
- 本组辨识的是独立训练权重对已知仿真模型遗漏项的估计，不是实机扰动识别；未引入完整变质量控制、高模态、接触、饱和鲁棒性或真实执行器标定。

## 复算

在工程根目录、具备原 NumPy/SciPy/Numba 环境下：

```powershell
python -B code/learned_residual_control.py --stage plan
python -B code/learned_residual_control.py --stage verify
python -B code/learned_residual_control.py --stage generator
python -B code/learned_residual_control.py --stage run
python -B code/learned_residual_control.py --stage audit
python -B results/learned_residual_control/report_tables.py
```

运行不会写入原控制或学习实验目录。缓存复用核对协议、输入与轨迹哈希。`summary.json` 保留全部结果，`generator_equivalence.json`、`residual_projection_verification.json`、`independent_verification.json` 和 `completion_audit.json` 分别保存生成函数等价、端口投影、轨迹指标及完整性核验。
