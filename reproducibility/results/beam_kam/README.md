# 同一两模态保守梁的KAM相关诊断

本目录使用学习数据的冻结参数和同一显式能量，不再用另一标量系统代替两模态梁。旧标量结果仍保留在 `results/kam/`。

```text
python code/beam_kam_diagnostics.py
```

所需 NumPy、SciPy、Numba、Matplotlib 版本及平台见 `protocol.json`。脚本只生成本目录、`manuscript/tables/beam_kam.tex` 和 `manuscript/figures/beam_kam.pdf/.png`；不读取或修改训练权重，不修改式（36）及之前的公式。

## 模型与数值口径

- 参数直接读自 `results/learning/inputs/reference_model_spec.json`，并与 `results/learning/data/seed_17.npz` 中的 nu、d 逐值一致校验；两个输入文件的SHA256存于 `protocol.json`。
- nu=(1, 6.152117504167307)，d=(0.2256707726832809, 0.3217988056102902)。时间满足 tau=11.417287282852458*t_SI。
- h_* = sum_j nu_j (X_j²+Y_j²)/2 + 1-cos(d·X) -(d·X)²/2。阻尼、接触、时变场输入为零。
- 三组参考半径为(0.05,0.05)、(0.12,0.10)、(0.20,0.16)，初相位固定为(0.37,1.13)。所有幅值处于学习数据的声明范围；约89.69秒的诊断时域比端到端比较时域更长，不构成实物长期有效性校核。
- 初值用 I0_j=r_j²/2 标记；它是谐振子参考初值参数，不是完整非线性系统的精确作用量。
- 全部轨迹积分至 tau=1023.9809220618276，即89.68688416903876秒；25601个共同输出样本，采样间隔tau=0.03999925476804014。
- 连续参考：DOP853，rtol=1e-12、atol=1e-14；中心轨迹加密为rtol=4e-14、atol=2e-16。三条基准轨迹、八条中心差分邻近轨迹和一条加密轨迹共十二条。
- 六级中点步长为真实教师h0=0.009999813692010035及h0/2、h0/4、h0/8、h0/16、h0/32，各级使用同一终点和共同采样时刻。
- 小角度正弦/余弦余项采用稳定Taylor求值，力项和势项的截断绝对上界分别为0.1^13/13!、0.1^14/14!，远小于双精度消去误差。大于0.1时使用直接三角函数；模型仍是同一显式h_*，没有增加物理项。

## 相位频率、分辨率与差分

主频估计使用 z_j=X_j-iY_j 的相邻相位增量 arg(conj(z_k)z_{k+1})，以 exp[-1/(s(1-s))] 光滑窗加权。共同采样下相邻相位增量小于pi，两个模态半径均远离零。

每条连续轨迹分别比较全窗、前半窗、后半窗和中心半窗，并另做二倍/四倍降采样。中心容差加密造成的最大频率变化为6.89e-13；分窗及降采样变化均不超过2.67e-15。这些是相互一致性指标，不是严格真实误差界。经验分辨阈值定义为

```text
max(1e-10, 10*最大分窗变化, 10*最大降采样变化, 10*中心容差加密变化)
```

本次阈值为1e-10，以tau的倒数计。FFT频率间隔约0.00614，只辨认两个主峰；1e-6至1e-5量级的非线性频移来自相位方法，不由FFT格点直接读取。

三组幅值的(omega1-nu1,omega2-nu2)为：

```text
(-2.0532472274e-6, -3.3235221901e-6)
(-8.9254621838e-6, -1.6193195397e-5)
(-2.3353353760e-5, -4.3513805966e-5)
```

中心参考初值I0=(0.0072,0.005)处，使用差分间距(0.0012,0.0010)及其一半，得到

```text
d omega/d I0 ~= [[-0.0003241100443585, -0.0013181829334741],
                [-0.0013181786144105, -0.0013401098284405]]
det = -1.303257496845257e-6
```

差分间距减半的矩阵最大变化为3.56e-12，领先四次Hessian与该矩阵最大差为3.32e-7。经验频率阈值传播得到的导数分辨量约为(1.67e-7,2e-7)。这个Jacobian描述固定初相位下的初值半径响应，不能当成精确作用量图中的Kolmogorov twist证书。

## 中点频率误差

`step_frequency_summary.csv`分别列出真实非线性模态频差和线性中点频差。观察阶为1.999386至1.9999999。中心工况的第二模态在h0下离散频率误差为0.0019392111，而物理频移约为0.0000161932，前者约为后者120倍。细化到h0/32后该离散误差降至1.895e-6。

隐式中点通过同一显式梁势的标量化方程求解，并用独立四维非线性方程核对九组一步更新；记录见 `implementation_verification.json`。长轨迹最大一步方程残差不超过8.68e-18。中点的相位误差与真实非线性频移分开报告。

## 文件与结论边界

- `summary.json`：所有工况的频率、分窗、采样、容差、能量漂移、差分Jacobian、阶数及输入哈希。
- `raw/continuous_*.npz`：十二条连续参考的共同时间、原始状态、初值、参数、容差与求解器调用次数。
- `raw/midpoint_level*.npz`：六级中点的原始状态、共同时间、步长与方程残差。
- `frequency_summary.csv`、`step_frequency_summary.csv`：便于独立核算的表格。

本次得到同一两模态梁的领先阶非退化性、有限时间双主频、可分辨的幅值依赖及约二阶步长收敛。没有建立完整h_*可积性、无穷阶Diophantine条件、严格正规形余项界、网络统一泛化界或KAM小性阈值，也没有给出已训练网络的不变环面认证。Shang1999定理1和Chen2022定理11仍按其各自可积性、光滑性、非退化与误差界前提引用；不将有限轨迹L2损失直接换成KAM结论，不将形式修正Hamiltonian视为现成精确系统。
