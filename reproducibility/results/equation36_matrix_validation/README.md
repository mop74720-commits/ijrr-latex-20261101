# 式（36）的质量维度与矩阵运算核验

本组回答质量不等于1、质量随构型变化，以及质量矩阵具有非对角耦合时，式（36）是否按所声明方式实现并表现出收敛。所有参数是运行前固定的数学基准，不属于新的梁质量本构或物理标定。

## 维度与模型

`q,p∈R^N`，状态顺序为全部q分量后接全部p分量，质量M和刚度K为N×N，状态和正则辛矩阵J为2N维。N=1时M是一个质量标量，而不是必定等于1；N=2时M为2×2，而不是4×4。

固定六类无阻尼、无独立外载荷基准：

| 类别 | M(q) | V(q) |
|---|---|---|
| scalar_m1 | 1 | q²/2 |
| scalar_m2 | 2 | q²/2 |
| scalar_m5 | 5 | q²/2 |
| scalar_variable | 2+.3q² | q²/2+.1q⁴/4 |
| coupled_constant | M0 | qᵀK0q/2 |
| coupled_variable | M0+.3qqᵀ | qᵀK0q/2+.1(qᵀq)²/4 |

N=2采用 `M0=[[2,.3],[.3,1.5]]`、`K0=[[1.7,.2],[.2,.9]]`。两者均对称正定，但不交换，交换子Frobenius范数为0.1979899。这使矩阵左解和运算次序得到实际检验。变质量M0+.3qqᵀ也在全构型空间正定。

Hamiltonian为 `H=.5 pᵀA(q)p+V(q)`，其中A=M⁻¹。恢复力写成K(q)q，`K=K0+beta(qᵀq)I`。严格保留

`∂_i A=−A(∂_i M)A`，`Delta_i=−.5 p_midᵀ∂_i A(q_mid)p_mid`。

按式（36）取 `epsilon=h² K A/4`，从左侧求解 `(I+epsilon)p_new=(I−epsilon)p_old−h Kq_old+h Delta`，系数和Delta均在中点计算。没有进行逐元素除法，也没有调换KA的次序。

## 协议与运行

每类3个固定初值、时域T=5、步长 `.2,.1,.05,.025,.0125`，共90条轨迹。N=1初值为 `(.7,.2),(-.4,.5),(.2,-.6)`；N=2初值在protocol.json逐项列出。初值是确定性测试点，不是随机训练种子，不作显著性检验。

常质量线性参考使用独立矩阵指数；变质量参考使用DOP853，容差5e−13/5e−15，并加密到5e−14/5e−16。原式（36）隐式残差采用Newton迭代与复步长Jacobian；另外独立求解标准Hamiltonian中点残差进行比较。最细步长下三个初值的最小观察阶约1.99987–1.99997。

每条轨迹首步以原式（36）对新旧状态的隐式Jacobian计算切映射，共90个辛结构探针；不是每一步或全域的数值认证。独立审计从标量Hamiltonian自动微分得到Hessian，构造对应中点切映射核对。质量最小特征值、条件数、非零Delta和每步残差全部保存。

## 故意错误实现的回归检查

在固定N=2非交换算例、h=.3时，以四维块矩阵的中点映射为独立基准：

- 正确矩阵左解与独立中点动量差为浮点舍入量级。
- 把左侧逆改为右侧逆，动量差为0.000454353。
- 把M⁻¹误作逐元素1/M，动量差为0.104874。

这两个错误实现均被明确检出，不以相同公式的重复计算作为唯一实现证据。

## 独立核验

`verify_independent.py`不导入实验实现。它从保存NPZ和协议重建标量能量，以PyTorch自动微分核对270个隐式中点，重新积分18个连续参考并复算90个终点误差/观察阶，用独立能量Hessian核对90个隐式切映射。结果：

- 独立参考终点差最大7.56e−16。
- 终点误差复算差最大7.88e−16。
- 差商标签与独立自动微分场差最大8.98e−13。
- 隐式切映射与独立能量Hessian切映射差最大4.44e−16。
- 原脚本、协议输入和所有90轨迹哈希匹配。

浮点辛缺陷为0的条目表示此次浮点运算结果为0，不据此声称数学上零误差或全域机器认证。观察二阶仅对应本组光滑保守基准，不替代原一般Birkhoff构造的阶数证明，也不验证任意阻尼或反馈。

## 文件与复算

`protocol.json` 在轨迹计算前保存模型、初值、步长、评价量、独立参考与源哈希；`execution_script.py` 为实际脚本快照。`results.json`、`comparison.csv`保留全部记录，`summary.json`汇总各类三个固定初值，`manuscript_table.tex`提供紧凑稿件表。`trajectories/`包含90份完整轨迹和首步切映射。

从工程根目录运行：

```powershell
python -B code/equation36_matrix_validation.py --stage plan
python -B code/equation36_matrix_validation.py --stage run
python -B results/equation36_matrix_validation/verify_independent.py
```

为保护运行历史，`--stage run`发现已有轨迹时拒绝覆盖。已有结果可以直接用`--stage summary`重新汇总或运行独立审计；全量重算应在新的复制目录中进行。本组没有改写原学习、控制或论文文件。
